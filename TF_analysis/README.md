# Transcription factor analyses

This module documents the transcription factor analyses used in the CLL STARR-seq study: motif enrichment with **SEA** (MEME Suite) and predicted allele-dependent binding changes with **FABIAN-variant**. It also documents the processing of publicly available LL-100 RNA-seq data for MEC-1 and HG-3 to obtain gene-level TPM values for TF expression annotation.

**This is a refactored, unvalidated code draft** based on the original R Markdown notebooks. Results from the cleaned scripts must be compared with the original files before the methods can be considered numerically reproduced. No final figures are included here.

## Data availability

The STARR-seq sequence library was designed for the associated study; its `element_id`-to-oligonucleotide `sequence` table is required for the FASTA and allele-comparison steps. It will be made available with the STARR-seq data when the study is published. The STARR-seq MPRAnalyze results are read from the adjacent `STARR-seq_analysis/` module.

RNA-seq data come from the **LL-100 panel** generated by the Leibniz Institute DSMZ: [CellDive](https://celldive.dsmz.de/rna/ll-100), [ENA PRJEB30312](https://www.ebi.ac.uk/ena/browser/view/PRJEB30312). The runs used in this analysis were **ERR3003563 (MEC-1)** and **ERR3003538 (HG-3)**. Reference transcripts and annotation are from GENCODE release 26. Motifs and annotations came from HOCOMOCO and JASPAR. See `docs/` for details. Original FASTQ and large derived files are not included.

## Running the code

Run from **inside `TF_analysis/`**, with the sibling `STARR-seq_analysis/` folder beside it. Files under `inputs/` are local inputs and are not included in the repository. Override paths with environment variables documented in `docs/input_formats.md`.

### RNA-seq quantification and TPM

Requires SRA Toolkit, fastp and Salmon (original analysis: Salmon 1.4.0), plus R packages `tximport`, `GenomicFeatures`, `AnnotationDbi`, `biomaRt` and `readr`.

```bash
bash RNAseq_processing/01_process_LL100_RNAseq.sh
Rscript RNAseq_processing/02_prepare_TF_expression.R
```

As in the original notebook, the script queries Ensembl through `biomaRt` to retrieve HGNC symbols and uses an inner merge with the gene-level TPM matrix. Since the original Ensembl release was not recorded and this is a live query, annotation labels may differ from those in the original TPM export. The numerical Salmon/tximport processing is otherwise preserved.

### SEA: common active oligonucleotides

```bash
Rscript scripts/01_prepare_SEA_inputs.R
sea --oc results/SEA/SEA_Both_active_dinuc --p results/SEA/inputs/Both_active.fa --order 1 --m inputs/motif_annotations/H12CORE_meme_format.meme
Rscript scripts/02_process_SEA_results.R
```

The script reads `results/SEA/SEA_Both_active_dinuc/sea.tsv` automatically when you run SEA locally. For online SEA runs, save `sea.tsv` under `inputs/SEA/` instead, or set `TF_SEA_RESULTS` to its actual path. `Both_inactive.fa` is exported for transparency but **not** used as a negative input by the documented SEA command. The actual SEA run generates shuffled dinucleotide-preserving controls (`--order 1`, no `--n`). See `docs/SEA_analysis.md`.

### FABIAN-variant

```bash
Rscript scripts/03_prepare_FABIAN_input.R
# Submit results/FABIAN/inputs/FABIAN_input_hg38.vcf to FABIAN-variant.
# Save the returned fabian_KnownTFBS.data as inputs/FABIAN/fabian_KnownTFBS.data.
Rscript scripts/04_process_FABIAN_results.R
```

FABIAN input is restricted to significant allelic-effect contrasts in enhancer-active constructs, and to SNPs whose REF base can be validated against the provided hg38 reference-base annotation. The score postprocessing uses absolute combined score >= 0.6, TFFM-preferred combination, and TF expression categories `high`/`very_high` in at least one cell line (TPM >= 30). See `docs/FABIAN_analysis.md`.
